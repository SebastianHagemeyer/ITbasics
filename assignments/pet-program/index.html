My First Program: The Pet Project

Build a real, working Python program from scratch, one small step at a time. You choose the pet and you choose the path: crunch numbers, or draw with a turtle.

How this works: everything happens on this page. Write and run your code in the editor below, follow the steps in order, and press Submit at the bottom when you're done. Your code saves automatically on this computer as you type. The Add to editor buttons drop example code at the bottom of whatever you've already written; merging it into your program (and deleting the old bits it replaces) is your job. There's always an Undo if it goes wrong. How you'll be marked is at the bottom (11 marks).

Step 0: Pick your path

Both paths teach the exact same skills (input(), int(), loops, if, and handling silly input) and both are marked with the same rubric. Pick the one that sounds more fun. You can switch any time; each path keeps its own saved code.

            New word: hardcoding. Typing the raw number straight into the maths,
            like pet_years = age * 7, is called hardcoding the value. It works,
            but that 7 is a mystery number: nobody reading the code knows what it means, and if it
            ever changes you have to hunt down every 7 in the program. The classier way is the big
            idea from the variables lesson: a variable is a name that embodies a value you
            set. Give the multiplier a name once, then use the name:
          

          

          

            Now the maths reads like English (age * dog_years), and if the vet tells you
            dogs actually age 6 times as fast, you change one line. From here on,
            keep using your named variable even where our example snippets are lazy and hardcode the 7;
            swapping it out is part of the job.

Part 0 Meet your pet turtle

          

            Congratulations, you've adopted a turtle. It lives in the panel above, it holds a pen, and
            it does exactly what your code says, nothing more, nothing less. These are the
            commands it understands (after import turtle):
          

          

            
CommandWhat the turtle does

            
              
turtle.forward(100)Walks 100 steps in the direction it's facing

              
turtle.left(90) / turtle.right(90)Turns on the spot (degrees)

              
turtle.pencolor("red")Changes the pen colour (names or hex codes)

              
turtle.pensize(5)Makes the line thicker

              
turtle.penup() / turtle.pendown()Stops / starts drawing while walking

              
turtle.circle(50)Draws a circle

              
turtle.speed(10)Walks faster (1 = slow, 10 = fast, 0 = instant)

              
turtle.write("hi")Writes text where it's standing
