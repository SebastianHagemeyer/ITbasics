The Number Guesser

The computer hides a number from 1 to 10. The player keeps guessing until they get it right. You have already met every piece of this in Task 1, now you put them together on your own.

Brief What to build

Write a program that:

  1. Picks a secret number from 1 to 10 that the player cannot see.
  2. Asks the player to guess, and turns their answer into a number.
  3. Keeps asking, over and over, while the guess is wrong.
  4. When the guess matches the secret, prints a success message like Correct! and stops.
This one is all yours. There is no starter code and no "load into editor" button on this page on purpose. Everything you need you used in the Pet Age Calculator: asking a question, turning text into a number, and a loop that keeps going until something is true. The one new tool is a way to pick a random number, that is the bit worth looking up. When you think it works, press Test my code below.
The only new idea: a random number. Python can pick one for you. The module is called random, and there is a function in it that gives back a whole number between a low and a high value you choose. Finding its name is part of the task, the documentation and the libraries lesson are fair game.

Check Does your game actually work?

        

          
Robot playtester. Press the button and a robot
          plays your game many times. It secretly knows the number each round (it forces Python's

          right, that a wrong guess leads to another guess, and that you only celebrate when the guess
