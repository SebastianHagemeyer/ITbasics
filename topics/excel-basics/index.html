1. What is a spreadsheet?

A spreadsheet is a file that stores data in a grid and can do calculations with it. Excel is the spreadsheet program most workplaces use; Google Sheets does the same job in a browser.

You've seen spreadsheets everywhere, even if nobody called them that: a sports ladder, a class roll, a shop's stock list, a game's leaderboard, a budget. Each row is usually one thing (one team, one student, one item) and each column is one fact about it (points, attendance, price).

Check your understanding: Which job is a spreadsheet not the right tool for?

A letter is mostly sentences and paragraphs, which is a job for a word processor like Word. Spreadsheets shine when data fits in rows and columns, especially numbers you want to calculate with.

2. Rows, columns and cells

A spreadsheet is a grid. Columns go down and have letters. Rows go across and have numbers. Where a column and a row cross is a cell, and each cell holds one piece of data.

Every cell has a name called its cell reference: its column letter, then its row number. So C6 is column C, row 6. Always the letter first. Click any cell below and watch the Name Box at the top left.

3. Getting data in

Click a cell and type. Then:

  • Enter saves it and moves down one cell.
  • Tab saves it and moves across one cell.
  • Ctrl + Z undoes a mistake.

Watch where things land in the cell. Text sits on the left. Numbers sit on the right. If a number is sitting on the left, Excel thinks it's text, and it can't do maths with it. The usual causes are a letter O typed instead of a zero, or a stray symbol in front of it.

Three of these scores look like numbers but Excel has read them as text. Click each one to find it, then retype it as a proper number (just click the cell and type; Enter saves).

4. When a column is too narrow

Two things go wrong when a column is too narrow for what's in it:

  • Text gets cut off, so you can't read the whole name.
  • Numbers turn into #####. Excel won't show half a number (that could trick you), so it shows hashes instead. The number is still there.

The fix: double-click the line between the column letters at the top, on the right edge of the column. Excel fits the column to its contents. Fix both columns below.

    6. Save it properly

    A file is no use if you can't find it next lesson. Save your work in a folder called Excel, inside a folder called Year 10 IT. Then give it a name that says three things:

    • Whose it is: your surname and first name.
    • What it is: Tournament.
    • Which version it is: v1 (next lesson, v2).

    Use underscores, not spaces: Surname_Firstname_Tournament_v1.

    Check your understanding: Which is the best file name?

    It's the only one that says whose it is, what it is and which version. "Book1" is what Excel calls every new file, so you'd never find it again.

    Glossary

    Spreadsheet
    A file that stores data in a grid and can do calculations with it.
    Cell
    One box in the grid. Each cell holds one piece of data.
    Row
    A line of cells going across. Rows have numbers.
    Column
    A line of cells going down. Columns have letters.
    Cell reference
    The name of a cell: column letter, then row number. B4 is column B, row 4.
    Name Box
    The box at the top left that shows the reference of the cell you've clicked.
    #####
    What Excel shows when a number doesn't fit. Widen the column.
